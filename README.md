# Картинки для писем рассылки

Хранилище открытое: ссылки отсюда стоят в письмах, и почта подписчиц грузит картинки прямо отсюда.

Как положить картинку: файл в корень, `git add`, `git commit`, `git push`. Ссылка для письма:
`https://raw.githubusercontent.com/ligacreate/email-assets/main/<имя-файла>`

Имена файлов латиницей, без пробелов: `cover-oktyabr-2026.jpg`. Уже отправленные картинки не удалять и не переименовывать — сломаются старые письма.

Сюда кладём только то, что и так уходит в письмо всем подписчикам. Скриншоты переписки, отзывы с именами и контакты — нельзя.
